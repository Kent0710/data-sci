## Overview of Current Projects

### Student Depression Analysis
- **Course:** Introduction to Data Science (2nd Year, 1st Term - DLSL)
- **Contributors:** Irish May Pureza, Julia Lois Mendoza, Kent
- **Description:** Exploratory data analysis (univariate, bivariate, Pearson correlation, and Cramér's V) and classification using Logistic Regression on 27,901 student records.
- **Validation Metrics:**
  - Accuracy: 85.56%
  - Precision: 86.12%
  - Recall: 89.33%
  - F1-Score: 0.8770
- **Documentation:** See [`student-depression/README.md`](./student-depression/README.md) for full analysis and setup instructions.
